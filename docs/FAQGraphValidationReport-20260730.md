# FAQ 그래프 검색 검증 보고서

## 1. 검증 목적

FAQ의 제목이나 대표 질문과 사용자 표현이 다르더라도 관련 답변을 찾고, 업무 범위 밖 질문은
답변하지 않는지 확인한다. 기존 `keyword`, `hybrid` 방식과 신규 `graph_hybrid` 방식을 같은
데이터와 질문으로 비교했다.

## 2. 검증 환경

- 일시: 2026-07-30
- 워크스페이스: `it_helpdesk_faq_voicebot_20260531`
- 데이터: 게시된 IT 헬프데스크 FAQ 36건
- 분야: PC, Office, Network
- 그래프 상태: 36건 `ready`, 누락/실패/오래된 구성 0건
- 질문: 총 42건, API 호출 126회
- 검색 방식: `keyword`, `hybrid`, `graph_hybrid`
- 검색 조건: `top_k=5`, `min_score=0.25`
- 그래프 조건: `graph_weight=0.35`, `min_similarity=0.60`, `max_hops=2`
- LLM 최종 선택: 사용하지 않음

질문은 원문 복사가 아닌 바꿔 말하기, 구어체, 증상 중심 표현, 동의어, 영문/한글 혼용,
제품 별칭, 기술 오류 코드, 정보가 부족한 질문, 범위 밖 질문으로 구성했다.

## 3. 구현 중 발견하고 수정한 문제

### 그래프 유사도 과대평가

그래프 시작 노드 검색 결과가 실제 벡터 유사도 대신 결과 순위로 점수화되고 있었다.
PostgreSQL 벡터 검색 결과에 실제 cosine 유사도를 포함하고, 설정된 최소 유사도보다 낮은
노드는 그래프 후보 점수에 반영하지 않도록 수정했다.

신규 그래프 설정의 기본 최소 유사도는 실제 테스트에서 오탐 억제가 가장 안정적이었던
`0.60`으로 변경했다. 기존 워크스페이스에 저장된 운영자 설정은 덮어쓰지 않는다.

### 제외 힌트 우회

제외 힌트가 키워드 점수만 차단하고 벡터 또는 그래프 점수가 같은 FAQ를 다시 후보로
추가할 수 있었다. 제외 힌트에 정확히 걸린 FAQ는 모든 검색 방식의 후보에서 완전히
제외하도록 수정했다.

### 표본 데이터 보강

현실적인 표현 차이를 검증하기 위해 10개의 대표 질문, 동의어, 키워드, 제외 힌트를
표본 FAQ에 추가하고 영향을 받은 그래프만 다시 구성했다. 예:

- `스프레드시트가 느리거나 멈춤`
- `PPT 글씨체가 다른 컴퓨터에서 바뀜`
- `webcam 웹캠 카메라가 켜지지 않음`
- `DNS_PROBE_FINISHED_NXDOMAIN`
- `앱이 응답 없음 상태예요`
- 제외 힌트 `토너`, `토너 구매`, `구매처`

## 6. 해석

그래프 검색은 문구의 직접 중복이 적은 PC와 Office 질문에서 효과가 컸다. 예를 들어
`부팅하는 데 한참 걸립니다`, `C드라이브가 꽉 찼다고 해요`, `docx가 읽기 전용`은
키워드와 기존 하이브리드가 선택하지 못했지만, FAQ와 연결된 증상/제품/용어 노드를 통해
정답을 찾았다.

`DNS_PROBE_FINISHED_NXDOMAIN`은 키워드 검색이 보안 에이전트 답변을 잘못 선택했지만,
벡터와 그래프 검색은 DNS 답변을 선택했다. 한글/영문 혼용과 제품 별칭도 Teams,
OneDrive, Wi-Fi 사례에서 정상 동작했다.

범위 밖 질문은 모두 거절했지만, `접속이 안돼요`, `느려요`처럼 문제 대상이 없는 질문은
유사도가 높은 FAQ를 선택했다. 이 경우 정답을 바로 반환하기보다 “어떤 서비스에 접속할 수
없으신가요?”와 같은 확인 질문으로 전환하는 정책이 필요하다.

## 7. 권장 운영값과 후속 과제

- 기본 검색: `retrieval_mode=graph_hybrid`
- 최소 선택 점수: `min_score=0.25`
- 그래프 최소 유사도: `min_similarity=0.60`
- 후보 수: `top_k=5`
- FAQ, 찾기 힌트, 동의어 변경 시 해당 FAQ 그래프만 자동 재구성
- 사용자가 대상을 말하지 않은 짧은 질문은 즉시 답변하지 않고 확인 질문으로 전환
- 실제 상담 로그의 미매칭 질문을 정기적으로 회귀 세트에 추가

이번 검증은 LLM 최종 선택 없이 수행했다. 따라서 평균 45.1ms의 검색 결과는 생성형 모델
호출 지연을 포함하지 않는다.
