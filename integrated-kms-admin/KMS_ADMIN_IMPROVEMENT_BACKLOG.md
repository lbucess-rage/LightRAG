# 통합 지식 어드민 개선 과제 메모

작성일: 2026-06-16

이 문서는 통합 지식 어드민을 일반적인 KMS 관점에서 비교했을 때 보강이 필요한 사용자 기능, UI, 설정 개선 과제를 기록한다. 내부 기술 구현, 서버 운영, 인프라 관점은 제외한다.

## 우선순위 1: 지식 운영 핵심 흐름

| 과제 | 현재 부족한 점 | 개선 방향 | 완료 기준 |
| --- | --- | --- | --- |
| 지식 승인 워크플로우 | 지식 등록 후 검수, 승인, 게시, 보관 단계가 명확하지 않음 | 초안, 검수 요청, 승인, 게시, 반려, 보관 상태와 역할별 액션을 제공 | 지식관리자와 관리자가 상태별 목록을 보고 승인/반려/게시 처리 가능 |
| 버전 관리 | 수정 이력은 제한적이며 이전 버전 비교/복원이 부족 | 지식 버전 목록, 변경 전후 비교, 특정 버전 복원 기능 제공 | 사용자가 지식 상세에서 이전 버전을 확인하고 복원 가능 |
| 지식 품질 관리 | 만료 예정, 오래된 지식, 저활용 지식, 무응답 키워드 기반 개선 대상이 부족 | 개선 필요 지식 큐를 제공하고 담당자가 처리 상태를 관리 | 품질 관리 화면에서 개선 대상, 담당자, 처리 상태를 확인 가능 |
| 검색 결과 피드백 | 사용자 피드백 수집 기능 부족 | 도움 됨/안 됨, 오답 신고, 누락 신고, 개선 요청 기능 제공 | 검색 결과별 피드백이 기록되고 지식 개선 후보로 연결 |

## 우선순위 2: 지식 작성 및 편집 UX

| 과제 | 현재 부족한 점 | 개선 방향 | 완료 기준 |
| --- | --- | --- | --- |
| 지식 작성 템플릿 | 등록 방식은 많지만 작성자가 어떤 형식으로 작성해야 하는지 안내가 부족 | FAQ형, 절차형, 공지형, 장애 대응형 템플릿 제공 | 지식 추가 시 템플릿 선택 후 기본 필드/본문 예시 자동 반영 |
| 리치 편집/미리보기 | 텍스트 입력 중심이며 작성 결과 미리보기가 제한적 | Markdown 미리보기, FAQ 답변 미리보기, 검색 결과 표시 형태 미리보기 제공 | 저장 전 실제 검색 결과에 보일 답변 형태를 확인 가능 |
| 대량 관리 | 여러 지식에 대한 일괄 변경 기능 부족 | 다중 선택 후 카테고리, 사용 여부, 유효기간, 태그, 보관 상태 일괄 변경 | 목록에서 체크박스로 여러 지식을 선택해 일괄 처리 가능 |
| 중복/유사 지식 탐지 | 등록 전에 유사 FAQ/문서 존재 여부를 알려주지 않음 | 제목/본문 입력 시 유사 지식 후보 표시 | 저장 전 유사 지식 목록과 병합/취소/무시 선택 가능 |
| 관련 지식 연결 | 관련 FAQ, 관련 문서, 대체 답변 연결 UI 부족 | 지식 상세에서 관련 지식, 상위/하위 지식, 대체 답변 연결 관리 | 사용자가 지식 상세에서 관련 지식을 추가/삭제 가능 |

## 우선순위 3: 검색 UX 및 검색 품질 설명

| 과제 | 현재 부족한 점 | 개선 방향 | 완료 기준 |
| --- | --- | --- | --- |
| 검색 세부 필터 | 카테고리 외 지식 유형, 상태, 태그, 출처, 기간 필터가 부족 | 통합 검색 조건에 유형/상태/태그/출처/기간 필터 추가 | 사용자가 원하는 범위로 검색 후보를 좁힐 수 있음 |
| 검색 결과 근거 설명 | 왜 해당 지식이 선택됐는지 설명이 부족 | 매칭 키워드, 사용 청크, FAQ 점수, 제외 사유를 결과별로 표시 | 결과 카드에서 선정 이유와 제외 이유를 확인 가능 |
| 검색 테스트 흐름 | 지식 등록 후 바로 검색 검증하는 흐름이 부족 | 등록 완료 후 "이 지식으로 검색 테스트" 액션 제공 | 신규/수정 지식에서 테스트 질문으로 검색 결과를 바로 확인 가능 |
| 검색 결과 비교 | 생성형 답변/FAQ 답변 비교 검증 기능 부족 | 같은 질문에 대해 생성형, FAQ, 통합 결과를 나란히 비교 | 지식관리자가 답변 출처별 품질을 비교 가능 |

## 우선순위 4: 카테고리 및 분류 운영

| 과제 | 현재 부족한 점 | 개선 방향 | 완료 기준 |
| --- | --- | --- | --- |
| 카테고리 이동/정렬 | 트리 구성은 가능하지만 운영 편의 기능이 부족 | 드래그 정렬, 상하 이동, 다른 부모로 이동 제공 | 카테고리 트리에서 순서와 부모를 직관적으로 변경 가능 |
| 카테고리 병합/복사 | 중복 카테고리 정리와 고객센터 간 복사 기능 부족 | 병합, 복사, 템플릿 적용 기능 제공 | 기존 지식 연결을 유지하면서 카테고리 병합/복사 가능 |
| 카테고리 권한 | 고객센터/역할별 카테고리 접근 권한이 부족 | 카테고리별 조회/관리 권한 설정 제공 | 역할 또는 담당 그룹별로 접근 가능한 카테고리 제어 가능 |
| 자동 분류 추천 | 지식 등록 시 카테고리 추천이 없음 | 제목/본문 기반 추천 카테고리 표시 | 등록 화면에서 추천 카테고리를 선택 가능 |

## 우선순위 5: 사용자와 권한 관리

| 과제 | 현재 부족한 점 | 개선 방향 | 완료 기준 |
| --- | --- | --- | --- |
| 권한 세분화 | 역할이 단순하여 실제 업무 권한 분리가 부족 | 조회, 등록, 수정, 삭제, 승인, 게시, 다운로드, API 관리 권한 분리 | 역할별 권한 매트릭스를 UI에서 설정 가능 |
| 조직/그룹 관리 | 사용자 개인 단위 관리 중심 | 팀, 부서, 고객센터 담당 그룹 단위 관리 제공 | 사용자를 그룹에 배정하고 그룹 권한을 적용 가능 |
| 사용자 활동 타임라인 | 사용 이력 조회는 있으나 업무 흐름 관점의 가시성이 부족 | 사용자별 활동 타임라인, 필터, 상세 보기 강화 | 사용자 상세에서 지식 등록/수정/검색/API 사용 이력 확인 가능 |

## 우선순위 6: 현황 및 통계

| 과제 | 현재 부족한 점 | 개선 방향 | 완료 기준 |
| --- | --- | --- | --- |
| 검색 품질 지표 | 단순 카운트 중심 | 무응답 검색어, 낮은 만족도 검색어, FAQ 미매칭, 생성형만 응답한 검색어 제공 | 품질 개선이 필요한 검색어 목록 확인 가능 |
| 지식 활용도 | 어떤 지식이 실제 답변에 많이 쓰였는지 부족 | 지식별 조회, 인용, 클릭, 피드백, 검색 노출 통계 제공 | 지식 상세에서 활용도와 품질 지표 확인 가능 |
| 통계 드릴다운 | 차트에서 상세 목록으로 내려가는 흐름 부족 | 키워드 클릭, 날짜 클릭, 카테고리 클릭 시 상세 로그/지식 목록 연결 | 통계 수치에서 원인 데이터까지 탐색 가능 |

## 우선순위 7: 외부 API 연동 사용성

| 과제 | 현재 부족한 점 | 개선 방향 | 완료 기준 |
| --- | --- | --- | --- |
| API 사용 문서 | API Key 발급 외 사용 문서가 부족 | 요청/응답 예시, 오류 코드, curl, JavaScript/Python 샘플 제공 | 외부 시스템 담당자가 화면에서 연동 문서를 확인 가능 |
| API 테스트 콘솔 | 발급된 API Key로 직접 테스트하는 화면이 부족 | API Key 선택, 질문 입력, 옵션 설정, 응답 확인 콘솔 제공 | 관리자가 외부 API 응답을 화면에서 즉시 검증 가능 |
| 연동별 품질 확인 | 외부 시스템별 검색 품질/장애 상태 확인이 부족 | 클라이언트별 호출 수, 실패율, 지연시간, 주요 검색어 제공 | API 관리 화면에서 연동 시스템별 사용 현황 확인 가능 |

## 우선순위 8: 온보딩과 도움말

| 과제 | 현재 부족한 점 | 개선 방향 | 완료 기준 |
| --- | --- | --- | --- |
| 초기 설정 가이드 | 처음 설정 시 어떤 순서로 진행해야 하는지 부족 | 고객센터 생성, 워크스페이스 연결, 기존 지식 연결, 카테고리 구성 가이드 제공 | 최초 진입 시 단계별 설정 체크리스트 확인 가능 |
| 필드별 도움말 | 게시판 API 매핑, 파서, 프롬프트 등 어려운 설정 설명이 부족 | 필드별 예시, 도움말, 샘플 값, 테스트 호출 제공 | 사용자가 설정 필드 의미와 예시를 화면에서 확인 가능 |
| 업무 친화 상태명 | 처리중/실패 등 시스템 중심 상태가 많음 | 검색 가능, 검수 필요, 오류 수정 필요, 보관됨 등 사용자 용어로 정리 | 목록과 상세에서 업무 상태를 직관적으로 이해 가능 |

## 개발 순서 제안

1. 지식 승인/버전/복원 흐름
2. 검색 피드백과 무응답/저품질 검색어 관리
3. 지식 상세 편집 UX와 대량 관리
4. 카테고리 이동/병합/권한
5. 외부 API 문서/테스트 콘솔
6. 통계 드릴다운과 지식 활용도 분석
