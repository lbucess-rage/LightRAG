# 통합 지식 어드민 도움말 원고 초안

작성일: 2026-06-22

이 문서는 통합 지식 어드민의 권한별 기능 도움말 초안입니다. 실제 도움말 화면에서는 시스템 관리자가 항목별 노출 여부를 조정할 수 있어야 하며, 각 항목에는 현재 화면 스크린샷을 반드시 연결합니다.

## 작성 기준

- 일반 사용자와 지식 관리자가 이해하기 쉬운 표현을 우선 사용합니다.
- 시스템 내부 용어는 필요할 때만 사용하고, 화면에서 쓰는 업무 용어로 풀어서 씁니다.
- 도움말 항목은 기능 단위로 나누며, 각 항목은 권한별 노출 설정이 가능해야 합니다.
- 스크린샷은 운영 데이터가 아닌 테스트 고객센터와 테스트 워크스페이스 기준으로 촬영합니다.
- API Key, 비밀번호, 개인정보, 민감한 고객 정보는 스크린샷에 노출하지 않습니다.

## 쉬운 용어 기준

| 시스템 용어 | 도움말 표현 |
| --- | --- |
| 워크스페이스 | 지식을 저장하고 검색하는 공간 |
| KMS 워크스페이스 | 문서, URL, 이미지 같은 일반 지식을 저장하는 공간 |
| FAQ 워크스페이스 | 질문에 바로 연결되는 FAQ 답변을 저장하는 공간 |
| 지식화 | 등록한 내용을 검색에 사용할 수 있도록 처리하는 작업 |
| 어드민 원장 | 어드민에서 관리하는 지식 정보 |
| LightRAG ref | 원본 지식과 연결된 내부 정보 |
| 벡터 재생성 | FAQ 답변 수정 내용을 검색에 다시 반영하는 작업 |
| 유효기간 | 지식이 답변 후보로 사용될 수 있는 기간 |
| 답변 후보 사용 | 이 지식을 검색 결과에 포함할지 여부 |
| 근거 지식 | AI 답변이나 FAQ 답변이 참고한 원본 자료 |

## 권한 설명

| 권한 | 설명 |
| --- | --- |
| 일반 사용자 | 통합 검색을 사용해 질문하고 답변과 근거를 확인하는 사용자 |
| 지식 관리자 | 지식을 등록, 수정, 연결하고 검색 반영 상태를 확인하는 사용자 |
| 시스템 관리자 | 고객센터, 사용자, API, 시스템 상태와 도움말 노출을 관리하는 사용자 |

# 도움말 항목

## HELP-SEARCH-001. 통합 검색 사용하기

| 항목 | 내용 |
| --- | --- |
| 메뉴 | 통합 검색 |
| 대상 권한 | 일반 사용자, 지식 관리자, 시스템 관리자 |
| 초기 노출 | 전체 노출 |
| 스크린샷 | `/help/screenshots/search/search-basic.png` |

### 이 기능은 언제 사용하나요?

고객 질문이나 업무 질문에 대해 AI 생성형 답변과 FAQ 답변을 함께 확인할 때 사용합니다. 질문을 한 번 입력하면 문서 기반 답변과 FAQ 기반 답변을 같은 화면에서 비교할 수 있습니다.

### 화면에서 확인할 것

- 질문 입력란에 검색할 내용을 입력합니다.
- `AI 생성형 답변`을 선택하면 문서 지식을 바탕으로 답변을 생성합니다.
- `FAQ 답변`을 선택하면 등록된 FAQ 답변 중 가장 가까운 답변을 찾습니다.
- 검색 결과에는 답변, 주요 키워드, 근거 지식이 함께 표시됩니다.

### 사용 방법

1. `통합 검색` 메뉴를 엽니다.
2. 질문 입력란에 질문을 입력합니다.
3. 필요한 경우 `AI 생성형 답변`, `FAQ 답변` 체크를 조정합니다.
4. 필요한 경우 카테고리 필터를 선택합니다.
5. `검색`을 누릅니다.
6. AI 답변과 FAQ 답변을 각각 확인합니다.

### 주의할 점

- 검색 결과는 현재 계정에 연결된 고객센터와 워크스페이스 범위 안에서만 나옵니다.
- 유효기간이 지났거나 사용하지 않도록 설정된 지식은 답변 후보에서 제외됩니다.
- 카테고리를 선택하면 해당 카테고리와 하위 카테고리에 연결된 지식만 검색 대상이 됩니다.

### 문제가 생기면 확인할 것

- 검색 결과가 없으면 선택한 카테고리 범위가 너무 좁지 않은지 확인합니다.
- 지식이 있는데 검색되지 않으면 지식 관리 화면에서 해당 지식이 어드민 원장과 연결되어 있는지 확인합니다.
- FAQ 답변이 나오지 않으면 FAQ 워크스페이스와 답변 사용 여부를 확인합니다.

## HELP-SEARCH-002. 카테고리로 검색 범위 좁히기

| 항목 | 내용 |
| --- | --- |
| 메뉴 | 통합 검색 |
| 대상 권한 | 일반 사용자, 지식 관리자, 시스템 관리자 |
| 초기 노출 | 전체 노출 |
| 스크린샷 | `/help/screenshots/search/search-category-filter.png` |

### 이 기능은 언제 사용하나요?

특정 업무 영역이나 고객 문의 유형 안에서만 검색하고 싶을 때 사용합니다. 예를 들어 `서비스 안내 > 이용 방법` 카테고리를 선택하면 그 범위에 연결된 지식만 답변 후보가 됩니다.

### 화면에서 확인할 것

- `카테고리 선택` 버튼을 누르면 선택 가능한 카테고리 목록이 열립니다.
- 체크한 카테고리만 검색 조건에 표시됩니다.
- 상위 카테고리를 선택하면 하위 카테고리의 지식도 함께 검색 대상에 포함됩니다.

### 사용 방법

1. 질문 입력란 아래의 `카테고리 선택`을 누릅니다.
2. 검색에 포함할 카테고리를 체크합니다.
3. 선택한 카테고리가 조건 칩으로 표시되는지 확인합니다.
4. 질문을 입력하고 검색합니다.

### 주의할 점

- 카테고리를 선택하지 않으면 전체 카테고리를 대상으로 검색합니다.
- 선택한 카테고리에 연결된 지식이 없으면 검색 결과가 줄어들 수 있습니다.
- 카테고리별 지식 카운트는 지식이 어드민 원장에 연결되어 있어야 정확하게 표시됩니다.

## HELP-SEARCH-003. 근거 지식 확인하기

| 항목 | 내용 |
| --- | --- |
| 메뉴 | 통합 검색 |
| 대상 권한 | 일반 사용자, 지식 관리자, 시스템 관리자 |
| 초기 노출 | 전체 노출 |
| 스크린샷 | `/help/screenshots/search/search-evidence.png` |

### 이 기능은 언제 사용하나요?

AI 답변이나 FAQ 답변이 어떤 자료를 참고했는지 확인할 때 사용합니다. 답변의 `[1]`, `[2]` 같은 번호는 화면 아래의 근거 지식 번호와 연결됩니다.

### 화면에서 확인할 것

- AI 답변 안의 번호를 누르면 해당 근거 지식 위치로 이동합니다.
- 근거 지식은 점수가 높은 순서로 우선 표시됩니다.
- 근거 지식 카드는 접고 펼칠 수 있습니다.
- 문서나 게시글 원본을 확인할 수 있는 경우 `본문 보기`, `게시글 보기`, `원본 보기` 버튼이 표시됩니다.
- 이미지 근거가 있는 경우 이미지 미리보기가 함께 표시됩니다.

### 사용 방법

1. 검색을 실행합니다.
2. AI 답변 또는 FAQ 답변 아래의 근거 지식 목록을 확인합니다.
3. 필요한 근거를 펼친다.
4. 원문이 필요하면 `본문 보기` 또는 `게시글 보기`를 누릅니다.
5. 이미지 근거가 있으면 이미지와 페이지 정보를 함께 확인합니다.

### 주의할 점

- `원본 링크 없음`으로 표시되면 원본 파일이나 게시글 주소가 어드민에 연결되지 않은 상태다.
- PDF에서 추출된 이미지 근거는 페이지 번호와 함께 표시됩니다.
- 근거 점수는 검색어와 자료가 얼마나 가까운지 판단하는 참고값입니다.

## HELP-SEARCH-004. 검색 후보 적용 내역 이해하기

| 항목 | 내용 |
| --- | --- |
| 메뉴 | 통합 검색 |
| 대상 권한 | 지식 관리자, 시스템 관리자 |
| 초기 노출 | 지식 관리자, 시스템 관리자 노출 |
| 스크린샷 | `/help/screenshots/search/search-eligibility.png` |

### 이 기능은 언제 사용하나요?

검색 범위에는 있었지만 답변 후보에서 제외된 지식이 있는지 확인할 때 사용합니다. 지식이 왜 검색되지 않았는지 파악하는 데 도움이 됩니다.

### 화면에서 확인할 것

- `검색 후보 적용 내역`에는 제외된 항목 수와 사유가 표시됩니다.
- `사용 안 함`은 답변 후보에서 제외하도록 설정된 지식입니다.
- `유효기간 만료`는 현재 날짜 기준으로 사용 기간이 지난 지식입니다.
- `FAQ KMS 제외`는 FAQ 답변 후보에서 제외된 항목입니다.

### 사용 방법

1. 검색을 실행합니다.
2. 오른쪽 정보 영역의 `검색 후보 적용 내역`을 확인합니다.
3. 제외된 지식명이 표시되면 지식 관리 화면에서 해당 항목을 확인합니다.
4. 필요한 경우 사용 여부나 유효기간을 수정합니다.

### 주의할 점

- 이 영역은 오류 메시지가 아니라 검색 후보를 어떻게 걸렀는지 알려주는 설명입니다.
- 일반 사용자에게는 혼란을 줄 수 있으므로 기본적으로 지식 관리자 이상에게만 노출하는 것이 적절하다.

## HELP-SEARCH-005. FAQ 하이브리드 검색과 공통 용어 이해하기

| 항목 | 내용 |
| --- | --- |
| 메뉴 | 통합 검색 |
| 대상 권한 | 지식 관리자, 시스템 관리자 |
| 초기 노출 | 지식 관리자, 시스템 관리자 노출 |
| 스크린샷 | `/help/screenshots/search/search-faq-hybrid.png` |

### 이 기능은 언제 사용하나요?

표현이 정확히 같지 않은 질문도 관련 FAQ를 찾게 하거나, 검색 결과가 나온 이유를 확인할 때 사용합니다. 예를 들어 사용자가 `팀즈 연결이 안 돼요`라고 질문해도 공통 용어 `팀즈 → Teams`와 의미 유사도를 함께 적용해 Teams 관련 FAQ를 찾을 수 있습니다.

### 화면에서 확인할 것

- `하이브리드`는 키워드 점수와 벡터 의미 유사도를 함께 사용합니다.
- `키워드`는 등록된 질문, 제목, 찾기 힌트와 일치하는 표현을 빠르게 찾습니다.
- `벡터`는 문장이 달라도 의미가 비슷한 FAQ를 보강합니다.
- 검색 결과의 `적용된 공통 용어`에는 실제로 확장된 표현이 표시됩니다.
- 최소 점수가 너무 높으면 관련 FAQ가 있어도 결과에서 제외될 수 있습니다.

### 사용 방법

1. 통합 검색의 검색 설정을 엽니다.
2. FAQ 조회 방식을 `하이브리드`로 선택합니다.
3. 질문을 입력하고 검색합니다.
4. FAQ 결과의 선택 방식과 적용된 공통 용어를 확인합니다.
5. 결과가 없으면 지식 관리의 `공통 용어`에서 동의어를 확인하거나 최소 점수를 조정합니다.

### 주의할 점

- 공통 용어는 워크스페이스 전체 FAQ에 적용되므로 승인 전에 영향 범위를 확인합니다.
- 벡터 검색은 표현 차이를 보완하지만 업무 의미가 다른 후보도 포함할 수 있으므로 키워드와 함께 사용하는 하이브리드가 기본값입니다.
- 답변 메모는 검색 점수에 사용되지 않습니다.

## HELP-KNOWLEDGE-001. 지식 관리 화면 이해하기

| 항목 | 내용 |
| --- | --- |
| 메뉴 | 지식 관리 |
| 대상 권한 | 지식 관리자, 시스템 관리자 |
| 초기 노출 | 지식 관리자, 시스템 관리자 노출 |
| 스크린샷 | `/help/screenshots/knowledge/knowledge-overview.png` |

### 이 기능은 언제 사용하나요?

등록된 지식을 확인하고, 새로운 지식을 추가하거나 기존 LightRAG 지식을 어드민 원장에 연결할 때 사용합니다.

### 화면에서 확인할 것

- 상단에서 KMS 워크스페이스와 FAQ 워크스페이스를 선택합니다.
- 카드 영역에서 전체 지식 수, 답변 후보 사용 수, 원장 미연결 수, 지식화 진행 수를 확인합니다.
- 지식화 방식 영역에서 파일, 텍스트, URL, FAQ 등 등록 방식을 선택할 수 있습니다.
- 지식 목록에서 제목, 유형, 출처, 카테고리, 상태, 사용 여부, 유효기간을 확인합니다.

### 사용 방법

1. `지식 관리` 메뉴를 엽니다.
2. 작업할 KMS 워크스페이스와 FAQ 워크스페이스를 선택합니다.
3. 지식 목록에서 현재 등록 상태를 확인합니다.
4. 새 지식을 등록하려면 `지식 추가`를 누릅니다.
5. 기존 LightRAG 지식을 연결하려면 `기존 지식 연결`을 누릅니다.

### 주의할 점

- 어드민에서 등록하거나 연결된 지식만 카테고리, 유효기간, 사용 여부 필터를 정확하게 적용할 수 있습니다.
- LightRAG 워크스페이스에 이미 있는 지식이라도 어드민 원장에 연결되지 않으면 통합 검색 후보 계산에서 빠질 수 있습니다.

| 스크린샷 | `/help/screenshots/knowledge/knowledge-common-settings.png` |

### 이 기능은 언제 사용하나요?

새 지식을 등록하기 전에 카테고리, 유효기간, 답변 후보 사용 여부를 정할 때 사용합니다.

### 화면에서 확인할 것

- `카테고리`는 지식을 분류하고 검색 범위를 제한하는 기준입니다.
- `유효기간`은 지식이 답변 후보로 사용될 수 있는 기간입니다.
- `답변 후보에 사용`을 끄면 지식은 저장되지만 검색 답변에는 사용되지 않는다.
- 태그는 지식을 찾거나 설명하는 보조 정보다.

### 사용 방법

1. 지식 추가 화면을 엽니다.
2. 지식화 방식을 선택합니다.
3. 카테고리를 선택합니다.
4. 필요한 경우 유효기간을 지정합니다.
5. 검색에 포함할 지식이면 `답변 후보에 사용`을 켠다.
6. 제목, 본문, 파일, URL 등 방식별 필수값을 입력합니다.

### 주의할 점

- 유효기간을 지정하지 않으면 만료 없이 계속 검색 후보에 포함됩니다.
- 이미 지난 날짜를 종료일로 지정하면 등록되어도 검색 결과에 포함되지 않을 수 있습니다.
- 카테고리를 잘못 지정하면 사용자가 통합 검색에서 해당 지식을 찾지 못할 수 있습니다.

4. 필요한 경우 FAQ 항목 설정에서 첨부 자료를 업로드하거나 외부 URL을 등록합니다.
5. 첨부 자료의 화면 표시 설명, 대체 텍스트와 검색용 설명을 입력합니다.
6. 태그, 카테고리, 유효기간, 사용 여부를 설정합니다.
7. `지식 추가`를 누릅니다.
8. 통합 검색에서 FAQ 본문과 첨부 자료가 함께 나오는지 확인합니다.

### 주의할 점

- 질문 후보에는 사용자가 실제로 입력할 만한 문장을 넣는 것이 좋습니다.
- FAQ 답변을 수정한 뒤에는 검색에 다시 반영되는지 확인해야 합니다.
- 같은 내용의 FAQ가 여러 개 있으면 사용자가 중복된 답변을 볼 수 있습니다.
- 콜봇은 이미지나 영상을 직접 전달할 수 없으므로 본문에는 음성으로 안내할 핵심 절차를 남겨야 합니다.
- 이미지 파일명만으로는 검색 품질이 낮습니다. “유심 교체 화면의 설정 메뉴 순서”처럼 사용자가 질문할 내용을 검색용 설명에 적습니다.
- 첨부 자료를 삭제하면 현재 답변에서는 숨겨지지만 이전 FAQ 버전을 복구하면 함께 복구할 수 있습니다.

## HELP-KNOWLEDGE-016. Excel과 DB 표에서 FAQ 일괄 생성하기

Excel 시트나 DB 테이블의 각 행을 FAQ 한 건으로 바꾸고, 생성 결과를 통합 어드민 원장에서도 관리하려면 `FAQ 일괄 생성`을 사용합니다. 한 번에 최대 1,000행을 처리할 수 있으며 Excel 파일은 최대 200MB까지 분석할 수 있습니다.

### 화면에서 확인할 것

- 1단계 `데이터 확인`에서 시트, 헤더 행, 데이터 시작 행과 샘플 데이터를 확인합니다.
- 2단계 `열 연결`에서 원본 ID, 제목, 대표 질문, 답변 본문, 분류, 상태와 유효기간 열을 지정합니다.
- `ID 조회형 FAQ`는 상세 설명으로 원본 ID를 찾아야 하는 표에 사용합니다.
- `AI 찾기 힌트 보완`은 대표 질문이나 동의어 열이 부족한 대량 데이터의 힌트를 일괄 생성합니다.
- 3단계에서 생성 건수, 게시 상태, 공통 태그와 작업 ID를 확인합니다.

### 사용 방법

1. 지식 관리 상단에서 `FAQ 일괄 생성`을 누릅니다.
2. `Excel` 또는 `DB/표 연결`을 선택합니다.
3. Excel은 파일을 고른 뒤 `Excel 분석`을 눌러 시트와 열을 확정합니다.
4. DB는 연결 정보를 등록하고 샘플 조회와 열 연결 미리보기를 확인합니다.
5. 원본 ID, 제목, 대표 질문, 답변 본문을 연결합니다.
6. 필요하면 AI 찾기 힌트 보완과 ID 조회형 FAQ를 켭니다.
7. 생성 전 요약을 확인하고 FAQ를 만듭니다.
8. 생성된 각 FAQ는 지식 목록과 작업 이력에 자동으로 연결됩니다.

### 예시

IT 헬프데스크 표의 `guide_id`, `issue_title`, `representative_question`, `answer_text` 열을 각각 원본 ID, 제목, 대표 질문, 답변 본문으로 연결합니다. 사용자가 `외부 모니터가 검은 화면이에요`라고 질문하면 `IT-HD-PC-003` FAQ를 찾고 상세 처리 절차를 답변할 수 있습니다.

### 주의할 점

- 시트를 바꾸거나 헤더 행을 수정하면 반드시 다시 분석해 열 목록을 갱신합니다.
- 게시 상태로 바로 생성하기 전에는 샘플 행과 찾기 힌트를 검토하는 것이 좋습니다.
- AI 보완은 비동기 작업입니다. 생성 후 작업 이력에서 완료 여부를 확인합니다.

## HELP-KNOWLEDGE-017. FAQ 공통 용어와 AI 후보 관리하기

### 이 기능은 언제 사용하나요?

제품 영문명, 한글 표현, 약어와 신조어처럼 여러 FAQ에 공통으로 쓰이는 표현을 한 곳에서 관리할 때 사용합니다. 등록자가 FAQ마다 `팀즈`, `Teams`, `MS Teams`를 반복 입력하지 않아도 됩니다.

### 화면에서 확인할 것

- `적용 중인 용어`에는 검색에 바로 쓰이는 승인된 용어 묶음이 표시됩니다.
- `AI 검토 후보`에는 FAQ 데이터에서 AI가 발견한 동의어·약어 후보가 표시됩니다.
- 후보의 근거, 신뢰도와 발견된 답변 수를 확인한 뒤 승인하거나 제외할 수 있습니다.
- 개별 FAQ의 찾기 힌트와 공통 용어는 별도로 관리됩니다.

### 사용 방법

1. 지식 관리 상단에서 `공통 용어`를 누릅니다.
2. 확실한 동의어는 대표 용어와 별칭을 직접 등록합니다.
3. 대량 FAQ를 분석하려면 `AI 후보 찾기`를 실행합니다.
4. 작업 이력에서 분석 완료를 확인합니다.
5. 후보 목록에서 근거와 신뢰도를 검토합니다.
6. 적절한 후보는 승인하고, 의미가 다른 후보는 제외합니다.
7. 통합 검색이나 FAQ 후보 검색에서 확장 내역을 확인합니다.

### 예시

대표 용어를 `Microsoft Teams`, 별칭을 `Teams`, `팀즈`, `MS 팀즈`로 승인하면 네 표현 중 하나를 사용한 질문이 같은 FAQ 후보군을 조회할 수 있습니다.

### 주의할 점

- `장애`, `오류`처럼 범위가 넓은 단어를 서로 같은 용어로 묶으면 관련 없는 FAQ까지 확장될 수 있습니다.
- AI 후보는 자동으로 적용되지 않으며 지식 관리자의 승인이 필요합니다.
- 삭제하면 이후 검색부터 확장이 중단되지만 기존 FAQ 본문이나 개별 찾기 힌트는 변경되지 않습니다.

## HELP-KNOWLEDGE-018. FAQ 그래프 구성과 그래프 결합 검색 사용하기

| 항목 | 내용 |
| --- | --- |
| 메뉴 | 지식 관리 |
| 대상 권한 | 지식 관리자, 시스템 관리자 |
| 초기 노출 | 지식 관리자, 시스템 관리자 노출 |
| 스크린샷 | `/help/screenshots/knowledge/knowledge-faq-graph.png` |

### 이 기능은 언제 사용하나요?

키워드나 문장 유사도만으로 구분하기 어려운 FAQ를 업무 대상, 의도, 제품, 증상과 같은 연결 관계까지 이용해 찾으려면 `FAQ 그래프`를 사용합니다. 기존 키워드·벡터 검색을 대체하지 않고 `그래프 결합` 조회를 선택한 요청에만 그래프 점수를 추가합니다.

### 화면에서 확인할 것

- `FAQ 그래프 사용`은 이 워크스페이스에서 그래프 결합 조회를 허용합니다.
- `변경 시 자동 갱신`은 FAQ 본문, 찾기 힌트와 공통 용어가 바뀔 때 해당 FAQ 그래프를 다시 만듭니다.
- `확실한 경우만 답변`은 최소 점수와 근거 종류 수를 검사합니다. 이를 통과한 후보가 여러 개이면 점수 차이가 작아도 가장 높은 후보 하나를 선택하고, 후보·분야 접전 여부는 진단 정보에 기록합니다.
- 확인 질문은 후보 점수 차이만으로 반환하지 않습니다. 후보가 없거나 점수가 낮은 경우, 또는 LLM ID 선택이 질문 의도를 명시적으로 모호하다고 판단한 경우에만 추가 정보를 요청합니다.
- `최소 AI 신뢰도`는 LLM ID 선택이 그래프 후보 중 하나를 고른 경우에도 확실하지 않으면 답변을 보류하는 기준입니다. AI 호출 실패, 잘못된 JSON, 후보 밖 ID도 기존 후보로 대체하지 않고 답변을 보류합니다.
- 엔티티 유형과 관계 유형은 그래프에 허용할 노드와 연결 종류입니다.
- `AI 추출 참고 프롬프트`는 정해진 스키마 안에서 업무 대상과 관계를 보완할 때만 사용합니다.
- 미리보기는 저장 전에 한 FAQ가 어떤 노드와 관계로 바뀌는지 보여줍니다.
- 구축 상태의 `갱신 필요`와 `미구축`은 그래프 결합 검색에 아직 반영되지 않은 FAQ 수입니다.

### 사용 방법

1. 지식 관리 상단에서 `FAQ 그래프`를 누릅니다.
2. 사용할 엔티티 유형, 관계 유형과 최대 관계 단계를 확인합니다.
3. FAQ 한 건을 선택하고 `미리보기`로 노드와 관계를 검토합니다.
4. 표 데이터처럼 관계 정보가 부족할 때만 `AI 추출 보완`을 선택해 다시 미리봅니다.
5. 설정을 저장하고 `미구축·변경 FAQ 구축`을 실행합니다.
6. 오답보다 미응답을 우선하려면 `확실한 경우만 답변`을 켜고 기본 보수성 기준으로 먼저 테스트합니다.
7. 완료 후 FAQ 후보 검수 또는 통합 검색에서 조회 방식을 `그래프 결합`으로 선택합니다.
8. 후보의 `그래프 연결 근거`와 답변 보류 사유에서 질문과 답변을 이어 준 근거와 부족한 조건을 확인합니다.

### 예시

`Teams 회의에서 마이크가 인식되지 않음` FAQ가 `Microsoft Teams` 제품, `회의 연결` 의도, `마이크 인식 실패` 증상과 연결되어 있다고 가정합니다. 사용자가 `팀즈 연결이 안돼요`라고 질문하면 공통 용어가 `팀즈`를 `Microsoft Teams`로 확장하고, 그래프가 같은 제품·의도에 연결된 FAQ를 보조 후보로 올립니다. 최종 선택은 기존 키워드와 벡터 점수에 그래프 점수를 합쳐 결정됩니다.

### 주의할 점

- 그래프 구축 전이나 갱신 필요 상태에서는 기존 하이브리드 검색으로 자동 대체되므로 기존 API 동작은 유지됩니다.
- 관계 단계를 크게 설정하면 먼 관계의 FAQ까지 후보가 될 수 있으므로 기본값 2단계부터 검증합니다.
- AI 추출 결과는 허용된 엔티티·관계 유형만 저장되지만, 운영 반영 전 미리보기 검토가 필요합니다.
- FAQ 삭제나 찾기 힌트 변경 후 자동 갱신을 끈 경우에는 수동 재구축을 실행해야 합니다.
- 정확도 우선 정책에서 `답변 없음`은 오류가 아닙니다. 범위 밖 질문, 정보가 부족한 질문, 분야와 후보가 갈리는 질문을 안전하게 보류한 결과일 수 있습니다.
- LLM ID 선택도 최소 점수, 필수 근거 수와 신뢰도 기준을 통과해야 합니다. 후보 간 점수 차이가 작다는 이유만으로 선택된 1위 답변을 취소하지는 않습니다.

- 카테고리를 바꾸면 통합 검색에서 해당 지식이 검색되는 범위도 달라집니다.

### 이 기능은 언제 사용하나요?

다른 시스템에서 통합 지식 어드민의 검색 API를 호출하도록 연결할 때 사용합니다.

### 화면에서 확인할 것

- API Key를 발급하고 활성 여부를 관리합니다.
- 외부 시스템별 KMS/FAQ 워크스페이스를 지정합니다.
- 호출 이력, 실패 여부, 예제 요청을 확인합니다.

- 유효기간과 사용 여부는 어드민 원장 기준으로 자동 적용되며, 외부 시스템이 임의로 우회할 수 없습니다.
