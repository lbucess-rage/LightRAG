# Knowledge Graph Schema - UI/UX 설계

## 1. UI 개요

### 1.1 설계 원칙
- **직관성**: 비개발자도 쉽게 스키마 관리 가능
- **시각화**: 스키마 구조를 그래프로 시각화
- **피드백**: 실시간 미리보기 및 검증 결과 표시
- **일관성**: 기존 LightRAG WebUI 디자인 시스템 준수

### 1.2 페이지 구조

```
LightRAG WebUI
├── Documents (기존)
├── Knowledge Graph (기존)
├── Query (기존)
├── Schema Manager (신규)  ←────────────────────────
│   ├── Schema Discovery      # 스키마 발견
│   ├── Template Library      # 템플릿 라이브러리
│   ├── Schema Editor         # 스키마 편집기
│   └── Current Schema        # 현재 적용된 스키마
└── Settings (기존)
```

## 8. 반응형 디자인

### 8.1 브레이크포인트

| 크기 | 범위 | 레이아웃 |
|------|------|---------|
| SM | < 640px | 단일 컬럼, 탭 드롭다운 |
| MD | 640-1024px | 2컬럼, 축소된 사이드바 |

### 8.2 모바일 최적화

- 드래그 앤 드롭 대신 파일 선택 버튼
- 그래프 시각화는 확대/축소 지원
- 모달 대신 전체 페이지 네비게이션
